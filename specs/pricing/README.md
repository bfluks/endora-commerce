# Pricing — standing analysis

The standing domain analysis of product pricing: how prices are stored and resolved today, how they
are read, how peer platforms do it, what the target model should be, and the scenarios a price
engine must answer. It outlives any one feature, so it sits here rather than under a
`specs/NNN-slug/` directory.

Start at `specs/conventions/pricing.md`, which says when to open which document and the working
rules for changing anything that touches a price. That file is the one index of this directory;
this README deliberately does not list the documents a second time (D-100).
