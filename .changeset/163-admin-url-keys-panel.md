The product editor's SEO tab gains a **URL keys** panel: the global key, a key per language and a key per sales channel and language (an empty field uses the inherited key; a key left behind by a channel the product left is shown as no longer used and can be removed), the storefront URL each channel and language ends up with, and — while the SEO module is on — the redirects old keys keep, each deletable after a confirmation. A key another product uses is refused naming that product; a key that is another product's redirect asks first, naming the product that loses it.
