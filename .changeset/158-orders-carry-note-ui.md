The order detail's *Comments* tab reads a custom-field carry system note in the operator's language: *System* as its author, the *Internal* marker, the quote request or sales opportunity the values came from, and one line per value not carried — the field's label where the Order definition can be read, else its key — with the reason. A note this screen cannot read shows its stored text.
